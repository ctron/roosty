= Roosty documentation

Roosty is a federated social server written in Rust.
It implements ActivityPub federation and Mastodon-compatible client APIs, uses PostgreSQL for durable multi-process operation, and includes a server-rendered Rust/WebAssembly frontend.

To see Roosty on the fediverse, https://openfollow.social/@rita@roosty.de[follow Rita at `@rita@roosty.de`].
